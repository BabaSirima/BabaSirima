### 📈 [Patient Churn | Survival Analysis](https://github.com/BabaSirima/patient-churn-coxph-survival-analysis)
Investigated not only **whether** patients churn, but also **when** churn is 
likely to occur using survival analysis.

- Developed **Cox Proportional Hazards models in R**
- Examined hazard ratios and patient-level risk factors
- Evaluated model performance using concordance and AIC
- Assessed proportional hazards assumptions
- Generated survival estimates to support churn-risk analysis

**Tech:** R • Survival Analysis • Cox PH • Statistical Modeling
